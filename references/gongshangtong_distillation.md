# 工伤通公众号写作风格深度蒸馏报告

基于2篇完整文章 + 5篇浏览摘要的分析（后续补充更多数据时更新）

---

## 一、标题清单与分类

| 序号 | 标题 | 类型 |
|------|------|------|
| 1 | 工伤赔偿标准知多少？ | 疑问型+干货型 |
| 2 | 明明是受指派工作受伤，劳动者工伤申请为何被驳回？ | 案例型+疑问型 |
| 3 | 抓机砸伤装卸工引纠纷，承揽还是劳务？法院判了 | 案例型+悬念型 |
| 4 | 人社局拒认工伤，法院：撤销重作 | 悬念型 |
| 5 | 超龄农民工下班途中车祸身亡，人社局拒受理工伤认定，法院：上下班途中不适用！ | 案例型+判决型 |
| 6 | 整理了最新的职工工伤与职业病致残等级分级标准 | 说明型+干货型 |
| 7 | 工伤通平台招募合作律师公告 | 公告型 |

**分类统计**：
- 案例型：3篇（43%）——最核心类型
- 疑问型：2篇（29%）
- 干货型：1篇（14%）
- 悬念型：1篇（14%）
- 公告型：零星出现

**标题规律**：
1. 案例型标题固定格式：「人物+事件+争议点+法院判决」，如「抓机砸伤装卸工引纠纷，承揽还是劳务？法院判了」
2. 疑问型标题格式：「XX知多少？」「XX为何被XX？」
3. 标题必含法律冲突或悬念点
4. 常用句式：「法院：XXXX」「人社局拒认XXX」——制造对抗感

## 二、开头方式

### 方式1：案例事实引入（出现4/7篇，57%）
直接讲案情，像讲新闻一样，不过度铺垫。

示例：「2024年，刘某经人介绍到某运输公司开挂车，双方未签订劳动合同，无固定工资，约定报酬按路程远近按趟结算。」

### 方式2：定义引入（出现2/7篇，29%）
用一句话定义核心概念，然后展开。

示例：「工伤赔偿标准，又称工伤保险待遇标准，一般是指工伤职工或者工亡职工亲属依法应当享受的赔偿项目和标准。下面，小编就和大家一起学习工伤赔偿标准的相关法律知识。」

### 方式3：引导关注（出现1/7篇，14%）
文首引导设为星标。

示例：「点击上方蓝字'工伤通'→点击右上角'...'→点'设为星标'」

**核心规律**：案例型文章一律用方式1；干货科普型用方式2。不客套、不寒暄，开门见山。

---

## 三、正文结构模式

### 模式A：案例解析型（最核心，出现最多）

固定结构：
```
【案情介绍】→ 事实经过，2-5段
↓
【争议焦点】→ 一句话点出核心法律问题
↓
【一审判决】→ 法院怎么判，引用法条
↓
【上诉理由】→ 当事人为什么不服
↓
【二审判决】→ 终审怎么判，引用法条，详细说理
↓
来源标注
```

**特点**：
- 案情介绍用【方括号标题】
- 争议焦点单独成节，一句话
- 一审二审逐层递进，像讲故事
- 判决部分必然引用法条

### 模式B：法规解读型

固定结构：
```
引言（定义+价值说明）→ 1段
↓
总述（核心要点列举）→ 1段
↓
分项详解（01/02/03...编号）→ 每项一段
  - 法条原文（黑体关键内容）
  - 大白话解读
↓
补充说明
↓
来源标注
```

**特点**：
- 用01/02/03两位数字编号
- 每项结构统一：法条+解读
- 分项之间有分割线

### 模式C：知识科普型

固定结构：
```
概念定义 → 范围说明 → 分级标准列举 → 补充说明
```

## 四、法条引用格式

### 精确格式（工伤通标准格式）

1. **法规名+条款号**：「《工伤保险条例》第三十条第三款」
2. **法规全称+文号+条款**：「《人力资源社会保障部关于执行《工伤保险条例》若干问题的意见（三）》（人社部发〔2025〕62号）第十条第二款」
3. **最高法文件**：「《最高人民法院行政审判庭关于超过法定退休年龄的进城务工农民因工伤亡的，应否适用〈工伤保险条例〉请示的答复》（[2010]行他字第10号）」

### 引用规律

- 精确到条、款、项，从不模糊引用
- 法条名称用书名号《》
- 文号用圆括号紧跟法规名
- 年份用六角括号〔〕
- 法条原文后紧跟黑体关键句
- 关键判决理由用**加粗**突出

---

## 五、加粗规律

| 加粗内容类型 | 示例 | 频率 |
|-------------|------|------|
| 核心法律结论 | **工伤认定通常以劳动关系的存在为基本前提** | 每篇必有 |
| 关键法律要件 | **在工作时间内、因工作原因伤亡** | 高频 |
| 判决关键句 | **由于刘某不具备工伤认定申请的主体资格，故人社局作出工伤认定申请不予受理决定** | 案例型必现 |
| 章节标题 | **01 医疗费** **【案情介绍】** | 全部 |
| 法律关系定性 | **而是一种劳务关系** | 案例型常见 |

**核心规律**：加粗用在3个位置——章节标题、法律结论、判决要点。不装饰性加粗。

---

## 六、分割线规律

- 用在章节之间：「————」或「---」
- 法规解读型文章：每个编号项之间都有分割线
- 案例型文章：【案情介绍】【争议焦点】等大章节之间用分割线
- 文末来源标注前有分割线

---

## 七、结尾话术变体

| 变体 | 示例 | 出现频率 |
|------|------|---------|
| 来源标注 | 「来源：中国工伤保险、网络」「来源：法宝网、修文县总工会」 | 100% |
| 免责/说明 | 「（文章配图均为AI生成）」 | 偶现 |
| 互动引导 | 暂未观察到硬性引流话术 | — |
| 安全提醒 | 「各方均需秉持安全第一的原则，共同防范风险」 | 偶现 |

**关键发现**：工伤通的结尾**非常克制**，不搞「关注我」「转发三连」等硬广。以来源标注收尾，偶尔加安全提醒。引流主要靠内容质量和公众号菜单，不是靠文末话术。

## 八、口吻与用词

| 维度 | 特点 |
|------|------|
| 自称 | 偶尔用「小编」，但不频繁 |
| 对读者称呼 | 「大家」「咱们」，但也不频繁 |
| 语气 | 严肃专业为主，偶尔口语化拉近距离 |
| 法条引用 | 极度精确、权威，像法律文书 |
| 案情描述 | 像新闻叙事，客观、冷静 |
| 判决分析 | 逻辑严密，层层递进 |
| 情绪控制 | 不煽情、不焦虑，不贩卖恐惧 |
| 专业术语 | 直接使用，不回避，但会配通俗解读 |

**核心定位**：「专业但不晦涩，严肃但不冰冷」——像一位严肃但耐心的律师在跟你讲案子。

## 九、排版规律

| 元素 | 规范 |
|------|------|
| 章节标题 | 【方括号标题】或**加粗标题** |
| 编号方式 | 法规解读型用01/02/03两位数字；案例型不用编号 |
| 色块 | 黄色/蓝色背景色块区分章节（微信编辑器样式） |
| 红色强调 | 重点标题用红色 |
| 分割线 | 章节之间用细线分割 |
| 段落长度 | 中等偏短，2-5句一段 |
| 法条引用 | 缩进+引用格式，与正文区分 |
| 来源标注 | 文末独立成段 |

## 十、可直接复制的文章模板

### 模板A：案例解析型（工伤通最核心模板）

```
【标题】人物/事件+争议点+法院：判决结论

【正文】

【案情介绍】

[时间]，[人物][做了什么/发生了什么]。[相关背景2-3句]。
[事件经过]。
[处理结果]。

【争议焦点】

[一句话点出核心法律问题。]

[一审/处理机关观点]

[法院/机关认为]，[引用法条]……
[判决/决定结论]。

[上诉/不服理由（如有）]

[当事人认为]，[理由]。

[二审/最终判决]

[法院认为]，[引用法条]……
[说理分析，逐层递进]。
[最终结论]。

---
来源：[来源1]、[来源2]
（文章配图均为AI生成）
```

```
【标题】XX标准/XX规定知多少？/ 最新XX标准整理

【正文】

[概念定义]，[又称XX]。下面，小编就和大家一起学习XX的相关法律知识。

————

[总述：核心要点列举]

————

**01 [项目1名称]**

依据《[法规名]》第X条第X款，[法条原文]。[大白话解读]。

————

**02 [项目2名称]**

依据《[法规名]》第X条第X款，[法条原文]。[大白话解读]。

————

[03-12依此类推……]

————

[补充说明部分]

---
来源：[来源1]、[来源2]
```

```

[概念定义]。

[范围说明]。

[分级/分类标准列举]：
- 一级：[标准]
- 二级：[标准]
- ……
```
