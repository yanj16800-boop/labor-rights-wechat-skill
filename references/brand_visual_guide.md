# 法律公众号品牌视觉规范

本文件负责视觉选用和装配，不负责生成或审核图片。若与根目录 `SKILL.md` 冲突，以 `SKILL.md` 为准。

## 视觉原则

- 专业、克制、清楚，避免廉价模板感和过度“律师化”。
- 图片服务具体内容，不为凑数量而配图。
- 同一篇文章保持统一色系和插画语言。
- 正文图不加文字，避免小屏阅读和 OCR 风险。
- 禁止使用未经授权的真人照片和可能侵权的素材。
- 默认使用 OpenClaw 当前已配置的生图能力，不绑定特定厂商、模型或接口。

## 资产选择顺序

配图员应按以下顺序提供资产：

1. 已发布或已审核资产库中与本文匹配的图片；
2. 候选库中主题、场景和色系匹配的图片；
3. 确实没有合适图片时再生成新图。

未采用但质量合格的新图进入候选库，保留主题、场景、色系、比例和可复用标签，不直接丢弃。

## 分类色系

| 内容方向 | 主色 | 辅助视觉 |
|---|---|---|
| 工伤认定与赔偿 | `#c24d76` | 工作场景、材料、流程、保障 |
| 交通事故责任与赔偿 | `#2f86b7` | 道路、车辆关系、责任与修复 |
| 劳动能力鉴定 | `#18a96f` | 检查、材料、等级与流程 |
| 人身损害伤残鉴定 | `#8b6fd6` | 鉴定、等级、证据与标准 |
| 混合主题 | 从文章主问题选主色 | 另一主题只作辅助色 |

这些颜色是方向，不是硬性模板。若配图与文章情绪冲突，应由视觉方案另行确定。

## 封面

- 接近微信公众号封面使用场景，采用宽幅构图。
- 标题文字应简短、清楚、可读；不把长标题完整塞入图片。
- 可使用人物、具体场景、材料或抽象元素，但必须与文章主题对应。
- 避免花哨字体、发光描边、3D 大字、密集法律符号和无关装饰。
- 生成完成后必须以真实图片进行 OCR、可读性和安全审核。

## 正文图

- 数量由文章内容和视觉方案决定，不机械规定为 2 至 3 张。
- 常用比例为 `16:9`，建议约 `900×506`；按实际接口选择最接近的受支持比例。
- 不为追求超大分辨率增加成本。
- 每张图必须对应明确段落或概念，并在排版包中有真实资产引用。
- 生成失败时不得用封面、占位图或文字描述冒充正文图。
- 只要视觉方案计划了正文图，缺少任何一张都必须退回配图员。

## 图片审核

图片进入排版前必须完成：

- 文件可读取；
- 内容与文章段落匹配；
- 无错误文字、乱码、水印和明显生成瑕疵；
- 无不当人物、机构标识或版权风险；
- 比例和清晰度适合公众号正文；
- OCR 与视觉审核结果来自真实图片，不接受仅修改元数据为“通过”。

审核未通过的图片返回配图员重新选图或生成；质量合格但本次未采用的图片进入候选库。

## 固定模块

- 不添加文首关注引导。
- 不使用分割线。
- 文末依次装配来源、图文说明、免责声明、真实延伸阅读链接、小程序入口和公众号名片。
- 某模块缺少真实数据时，省略或退回补充，不得伪造链接、名称或标识。
