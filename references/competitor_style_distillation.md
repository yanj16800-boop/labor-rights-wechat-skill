# 对标公众号写作风格蒸馏

## 一、「工伤通」写作风格分析

### 1. 标题特征
- **疑问型**：「工伤赔偿标准知多少？」用疑问句引发好奇
- **案例型**：「抓机砸伤装卸工引纠纷，承揽还是劳务？法院判了」包含案例+法律问题+判决结果
- **悬念型**：「人社局拒认工伤，法院：撤销重作」制造冲突感
- **说明型**：「整理了最新的职工工伤与职业病致残等级分级标准」直接说明价值
- 标题必含「工伤」品牌词；多用疑问句和感叹号；突出核心价值或冲突点

### 2. 开头引入
- **定义引入**：工伤赔偿标准，又称工伤保险待遇标准，一般是...
- **直接切入**：直接进入主题，无多余寒暄
- **案情概述**：用1-2句话概括案例核心事实
- **引导关注**：点击上方蓝字'工伤通'→点击右上角'...'→点'设为星标'
- 不客套、不啰嗦，开门见山，尊重读者时间

### 3. 正文结构
| 文章类型 | 结构模式 |
|----------|----------|
| 法规解读 | 总述→分点列举（1.2.3...）→子项细分（1.1/1.1.1...） |
| 知识科普 | 赔偿项目（12项）→赔偿标准（逐项详解） |
| 案例解析 | 基本案情→争议焦点→法院判决→法官说法→安全提醒 |

排版：黄色/蓝色背景色块区分章节，红色标题强调重点，数字编号清晰，层级分明

### 4. 法条引用方式
- 精确到条、款、项：「《工伤保险条例》第三十条第三款」
- 法条原文+结合案情分析，不是简单堆砌
- 黑体字突出关键法条内容
- 法条与案例紧密结合

### 5. 语气口吻
- **专业但不晦涩，严肃但不冰冷**
- 使用法律术语但不过度学术化
- 偶尔用「咱们」「大家」等口语化表达拉近距离
- 陈述事实，不主观臆断
- 注重可操作性，给读者明确指引

### 6. 结尾引流
- 行动号召：「欢迎关注'工伤通'，获取更多工伤法律知识！」
- 放置微信号二维码+「欢迎咨询」
- 安全提醒：「各方均需秉持安全第一的原则，共同防范风险」
- 来源标注：「来源：法宝网、修水县总工会」
- 不硬广、不套路，以价值输出为主，软性引导关注

### 7. 核心成功要素
1. 垂直领域深耕：专注工伤法律，建立专业形象
2. 内容结构化：标题、分段、编号清晰易懂
3. 法条精准引用：增强权威性和可信度
4. 案例驱动：用真实案例讲解法律，生动易懂
5. 品牌一致性：每篇文章都强化品牌

## 二、「鉴定政策」写作风格分析

### 1. 标题特征
- **前缀式**：「头条｜重磅！」制造紧迫感和重要性
- **书名号突出核心**：「《2018年最有影响力的十大鉴定政策》」
- **仪式感收尾**：「出炉！」带发布宣告感
- 整体风格：新闻公告式强调语气

### 2. 开头引入
- **时间过渡引入**：用年份更替/时间节点自然引出话题
- **数据支撑**：用具体数字体现专业性和工作量
- **口语化表达**：「据小编不完全'盘点'」拉近距离
- **主题点题**：符合时令惯例（年终盘点等），接地气

### 3. 正文结构
```
引言 → 投票说明 → 十大政策列表（numbered list）→ 每条政策解读 → 致谢 → 推荐阅读
```
- 每条政策统一格式：圆形数字编号①②③ + 政策全称+文号 + 【政策提示】解读
- 按重要性/得票数排列
- 分段清晰，每条政策独立成块

### 4. 法条引用方式
- **文号在前，名称在后**：国务院令第701号《医疗纠纷预防和处理条例》
- 括号标注年份：〔2018〕、［2018］
- 政策名称用下划线/蓝色突出
- 【政策提示】板块：每条政策后附通俗化解释

### 5. 语气口吻
- 专业严肃：引用完整文号，体现权威性
- 通俗解读：口语化开头+政策解读降低门槛
- 互动性强：投票机制+致谢增强参与感
- 用「小编」自称拉近距离

### 6. 结尾引流
- 直接致谢：「特别感谢各位参与投票的朋友！」
- 情感共鸣：「您的支持是我们奋斗前行的最大动力」
- 简洁有力，不拖沓
- 推荐阅读引导关注其他文章

### 7. 排版特点
- 绿色边框卡片式布局，视觉统一
- 圆形数字编号（①②...）清晰标识
- 蓝色标题文字（clickable感觉）
- 【政策提示】标签区分解读内容
- 灰色背景框推荐阅读
- 每条政策独立成块，间距适中

### 8. 可复用模式
- **盘点型文章**：引言→投票说明→编号列表→每条解读→致谢→推荐阅读
- **政策解读型**：政策全称+文号→【政策提示】通俗解读→实操要点

## 三、综合对比与融合要点

| 维度 | 工伤通 | 鉴定政策 |
|------|--------|---------|
| 核心模式 | 案例解析驱动 | 政策盘点/解读驱动 |
| 法条引用 | 精确到条款项+案情结合 | 文号+全称+通俗解读 |
| 语气 | 严肃专业+偶尔口语 | 专业严肃+互动参与 |
| 开头 | 案例/冲突直接切入 | 时间/数据铺垫引入 |
| 结尾 | 价值输出+软引导 | 致谢+情感连接+推荐 |

**融合应用到我们公众号：**
- 日常文章走工伤通的「案例解析型」，用案例讲故事、用判决建权威
- 法条引用学习工伤通的精确度+鉴定政策的解读方式
- 盘点类文章走鉴定政策的模式
- 排版取两家之长：工伤通的色块分区+鉴定政策的卡片式独立成块
