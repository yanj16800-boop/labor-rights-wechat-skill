## API 限制

- **search_knowledge**: 可以搜索订阅知识库，返回文件标题（highlight_content 通常为空）
- **get_media_info**: 订阅知识库文件返回 220030（"没有权限通过skill获取订阅知识库的文件"），无法获取原文
- **API 调用次数限制**: 有每日上限，达上限后返回 220021（"资料获取次数已达上限，请明天再尝试"）
- **正确参数**: `query` + `cursor`（空字符串）+ `knowledge_base_id`，不需要 `count`/`search_type`/`limit`

## 写作联动方式

1. **选题/法律核实时**: 用 `search_knowledge` 搜索相关订阅知识库，确认相关法律文件存在
2. **法律条文核实**: 结合本地 `legal_database.md` 和搜索到的文件标题交叉验证
3. **案例参考**: 搜索结果中的案例文件标题可提供案例线索，用搜索引擎获取详细内容
4. **查重**: 搜索自己的"公众号已发布文章"知识库（`j4lqA_gbe2oT_vvU86HhoDhXxAeVuCnhTlb8Mv6SwXY=`）
5. **多库联动**: 劳动法库搜工伤/劳动关系，交通事故库搜事故赔偿，司法鉴定库搜伤残等级标准
