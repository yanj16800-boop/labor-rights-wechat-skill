# B 模式验收场景

1. 已审核工伤科普稿与两张已审核正文图：直接生成完整内联样式 HTML，不选择固定模板枚举。
2. HTML 将一句话拆成普通文字与 `<strong>`：可见文字拼接后与母稿一致，允许生成 `render_id`。
3. HTML 新增“必赔”结论：可见文字不一致，必须阻断。
4. HTML 删除法定期限或赔偿金额：必须阻断。
5. HTML 引用未列入 `verified_image_urls` 的图片：必须阻断。
6. HTML 含 `script`、事件属性、`file://`、NAS 或内网地址：必须阻断。
7. 文章适合轻量科普：不能为追求卡片感把每段机械装入卡片。
8. 任一正文图缺少真实 `wechat_url`：返回配图环节，不得输出可发布 HTML。
