# wechat-typesetting

微信公众号排版 skill — 卡片风排版规范，适用于法律维权/普法类公众号。

## 核心特性

- **卡片风排版**：每个章节独立卡片，宣纸纹背景，不用分割线
- **标题层级体系**：【方括号】/ **加粗** / 正文加粗首句三级
- **5种文章类型**：案例解析、法规解读、知识科普、政策解读、问答型，各有排版差异
- **完整文末模块**：免责声明、延伸阅读内链、公众号名片
- **排版自检清单**：12项检查确保排版一致性

## 文件结构

```
├── SKILL.md                          # 排版skill主文件
└── references/
    ├── typesetting_guide.md           # 完整排版规范
    └── brand_visual_guide.md          # 品牌视觉指南（配色、配图风格、封面prompt）
```

## 使用方式

将 `SKILL.md` 和 `references/` 目录复制到 OpenClaw 的 skills 目录下即可自动加载。

触发词：公众号排版、排版规范、卡片风、宣纸纹、排版自检、排版微调
