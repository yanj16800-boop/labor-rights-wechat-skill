# labor-rights-wechat-layout

法律微信公众号排版与视觉装配 Skill，适用于工伤、交通事故、劳动能力鉴定和人身损害伤残鉴定内容。

## 核心特性

- 多种移动端排版模板按内容自动选择；
- 已审核正文母版不得被排版环节实质改写；
- 正文图片计划数、审核数和实际引用数必须一致；
- 缺图自动返回配图员，需要改正文自动返回写手；
- 不使用文首关注引导和分割线；
- 保留免责声明、真实延伸阅读、小程序和公众号名片。

## 文件结构

```
├── SKILL.md                          # 唯一主规则
└── references/
    ├── typesetting_guide.md           # 完整排版规范
    └── brand_visual_guide.md          # 品牌视觉指南（配色、配图风格、封面prompt）
```

## 使用方式

将 `SKILL.md` 和 `references/` 目录安装到负责排版的 Agent 工作区。

本 Skill 不负责选题、研究、写作、生图、OCR、最终审核或公众号推送。
